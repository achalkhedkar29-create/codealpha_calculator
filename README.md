# Calculator

A simple and user-friendly web-based calculator built using **HTML, CSS, and JavaScript**.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear button
* Easy-to-use interface
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the Calculator project folder.
3. Open `index.html` in a web browser.
4. Use the calculator to perform arithmetic operations.

## Project Purpose

This project was created to practice basic web development concepts, including HTML structure, CSS styling, and JavaScript functionality.
